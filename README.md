
# Python Expense Tracker

A simple, interactive expense tracking web application built with Python and Streamlit. Add expenses, organize them by category, and monitor your total spending through a clean web interface.

## Live Demo

[Open Expense Tracker](https://pythonexpensetracker-sgnhczsgd2stggup5e6jzn.streamlit.app/)

## Features

- Add expenses with a name, amount, category, and date.
- View total spending and the number of recorded expenses.
- Review expense history.
- Save and load expense data using JSON.
- Clear all expenses with confirmation.

## Tech Stack

- Python
- Streamlit
- JSON
- Git and GitHub

## Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/kirnakumari/python_expense_tracker.git
   ```

2. Open the project folder:

   ```bash
   cd python_expense_tracker
   ```

3. Install dependencies:

   ```bash
   python -m pip install -r requirements.txt
   ```

4. Run the application:

   ```bash
   python -m streamlit run app.py
   ```
