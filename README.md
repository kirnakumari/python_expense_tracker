# Python Expense Tracker

A simple, interactive expense tracking web application built with Python and Streamlit. Add expenses, organize them by category, and monitor your total spending through a clean web interface.

## Features

* Add expenses with a name, amount, category, and date.
* View your total spending.
* See the number of recorded expenses.
* Review your expense history.
* Save and load expense data using JSON.
* Clear all recorded expenses with confirmation.

## Tech Stack

* Python
* Streamlit
* JSON
* Git and GitHub

## Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/kirnakumari/python_expense_tracker.git
   ```

2. Open the project folder:

   ```bash
   cd python_expense_tracker
   ```

3. Install the required dependency:

   ```bash
   python -m pip install -r requirements.txt
   ```

4. Start the application:

   ```bash
   python -m streamlit run app.py
   ```

5. Open the local URL shown in your terminal.
